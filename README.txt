FLOWMETER CALIBRATION APP - ANDROID INSTALLATION

1. Extract this ZIP to a web server or approved internal SharePoint/static website that serves files over HTTPS.
2. Open index.html in Chrome or Edge on the Android phone.
3. Tap INSTALL APP. If no prompt appears, use the browser menu and choose Install app or Add to Home screen.
4. After the first load, the service worker caches the app for offline use.

Standalone option:
Open Flowmeter_Calibration_Offline.html directly on the phone. It works offline, but Android does not treat a file:// HTML page as an installed PWA. Use DOWNLOAD APP to make another copy of the HTML file.

Data is stored locally in browser storage. Export calibration history to CSV before clearing browser data or uninstalling the PWA.
